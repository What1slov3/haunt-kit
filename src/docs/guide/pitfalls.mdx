# Частые ошибки

Симптом → причина → что делать. Почти всё ниже однажды уже случилось в ките; причины записаны, чтобы не
искать их второй раз.

## Слои и анимации

| Симптом                                                    | Причина                                                                                                                   | Что делать                                                                                               |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| меню или поповер не закрывается, закрытый слой висит в DOM | `animation: haunt-pop-out` в CSS-модуле: имя keyframes локализовано, анимация не нашлась, Radix ждёт `animationend` вечно | `animation: var(--anim-pop-out)` — переменные из `theme/animations.css`                                  |
| слой без триггера оставляет фокус на `<body>`              | Radix возвращает фокус на триггер, а его нет (палитра по сочетанию, диалог из пункта меню)                                | `lib/use-return-focus.ts`                                                                                |
| в консоли предупреждение Radix про `Description`           | `Dialog.Content` без описания                                                                                             | `aria-describedby={undefined}`                                                                           |
| всплывающее внутри `AccentScope` в цветах приложения       | свой `container` у портала или портал мимо `usePortalContainer()`                                                         | не передавать `container`: хост скоупа подставляется сам                                                 |
| `HoverCard` недоступен с клавиатуры                        | так устроен Radix HoverCard — только мышь                                                                                 | то же содержимое — ещё и по клику; карточка профиля — `ProfileHoverCard` (`trigger="both"` по умолчанию) |

## Тема, акцент, токены

| Симптом                                                    | Причина                                                                              | Что делать                                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| во вложенной светлой `ThemeScope` один цвет остался тёмным | производный токен объявлен только на `:root`: `var()` вычислился там и унаследовался | объявлять в блоке `:root, [data-theme]`                        |
| внутри `AccentScope` производный цвет акцента не меняется  | производная от акцента объявлена на `:root`                                          | в блок `*` в конце `tokens.css`                                |
| светлая тема мигает тёмной при загрузке                    | тема ставится в эффекте после рендера                                                | `initTheme()` и `initEffects()` в `main.tsx` до `createRoot`   |
| компонент не меняется в «сигнале»                          | читает токен без запасной ручки или задаёт цвет hex                                  | ручка `var(--knob, основа)` и токены                           |
| в «сигнале» круглое внутри квадратного                     | вложенный элемент сам задаёт себе скругление (`--avatar-radius` на аватаре)          | обнулить на самом элементе селектором сильнее его класса формы |
| `ThemeProvider` не видит смену темы из тулбара             | он читает тему с `<html>` один раз при монтировании                                  | `key={theme}` — пересоздание при смене                         |

## Раскладка и прокрутка

| Симптом                                            | Причина                                                                                               | Что делать                                                                |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `Text truncate` не обрезает                        | у флекс-родителя нет `min-width: 0`                                                                   | `min-width: 0` родителю, `grow` — флекс-ребёнку                           |
| `AmbientBackground` не виден                       | родитель создаёт свой контекст наложения (`transform`, `filter`, `opacity < 1`)                       | убрать у родителя или фон в рамке: `fixed={false}` + `isolation: isolate` |
| `VirtualList` не прокручивается                    | положили внутрь `ScrollArea`                                                                          | у `VirtualList` своя область прокрутки                                    |
| системная серая полоса прокрутки со стрелками      | у элемента `scrollbar-width` / `scrollbar-color`: в Chromium 121+ это выключает `::-webkit-scrollbar` | убрать: полоса кита — глобальная (`theme/global.css`)                     |
| `AppShell` в узком окне не уводит панели в `Sheet` | пороги — по ширине оболочки, а не окна                                                                | `breakpoints` под свою раскладку                                          |

## Строки и тесты

| Симптом                                           | Причина                                                             | Что делать                                                                       |
| ------------------------------------------------- | ------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| падает `no-hardcoded-strings.test.ts`             | кириллица в строке компонента                                       | ключ в словаре и `useUiStrings()`; данные — в `EXCEPTIONS` с причиной            |
| падает `tokens.test.ts`                           | токен добавлен или переименован в CSS без пересборки                | `pnpm --filter @haunt/ui build:tokens`                                           |
| падает `tui-font.test.ts`                         | правили геометрию глифов без пересборки                             | `pnpm --filter @haunt/ui build:tui-font`                                         |
| история падает в полном прогоне и проходит одна   | гонка под нагрузкой                                                 | `waitFor` / `findBy` вместо мгновенной проверки, без `sleep`                     |
| «Vite unexpectedly reloaded a test»               | зависимость нашлась посреди прогона                                 | добавить её в `optimizeDeps.include` проекта `storybook`                         |
| `useTheme: оберните приложение в <ThemeProvider>` | компонент с `useTheme` вне провайдера (например, в MDX без обёртки) | `ThemeProvider` в корне; в Storybook это делают декоратор и `HauntDocsContainer` |

## Шрифты и знаки

| Симптом                                          | Причина                                                                  | Что делать                                                           |
| ------------------------------------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------------------- |
| рамка `┌─┐` рвётся пунктиром, блоки не стыкуются | знак рисует системный шрифт: элемент не на `--font-mono`                 | `font-family: var(--font-mono)`, строка — `--tui-leading`            |
| между строками псевдографики щель                | межстрочный больше клетки шрифта                                         | `line-height: var(--tui-leading)` (1.32)                             |
| русский заголовок в «сигнале» другим шрифтом     | у выбранного дисплейного шрифта нет кириллицы — рисует следующий в стеке | шрифт с кириллицей: Unbounded, Oswald, Exo 2, Tektur                 |
| звук не играет                                   | уровень `off` по умолчанию или не было жеста пользователя                | `sound.setLevel('on')`; `AudioContext` создаётся после первого клика |

## Не повторять чужое

| Симптом                                           | Что делать                                                                                                                                                  |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| новый экран узнаётся как Discord                  | сверить с таблицей 10c в `docs/ui-kit.md`: острова вместо колонок встык, аура вместо пилюли рейла, след автора вместо шпоры ответа, TUI-метки вместо пилюль |
| хочется скопировать удачный приём чужого продукта | взять идею, а форму найти в своём словаре: TUI-знаки, примитивы Haunt (поток, сцена, лор), аура и след                                                      |
