# Быстрый старт

От пустого приложения до первого экрана на ките за пять шагов: зависимость, стили, провайдеры, раскладка,
дополнительные входы. Всё, что ниже, уже так устроено в `apps/web` — его можно открыть рядом как образец.

> Кит — исходники без сборки. Приложение собирает его своим Vite: правка в `packages/ui/src` видна в
> приложении сразу, без шага сборки и без перезапуска.

## 1. Зависимость

Пакет живёт в монорепозитории, приложение берёт его из рабочей области:

```json title="apps/<приложение>/package.json"
{
  "dependencies": {
    "@haunt/ui": "workspace:*",
    "react": "^19.0.0",
    "react-dom": "^19.0.0"
  }
}
```

`react` и `react-dom` — peer-зависимости: одна копия на приложение. Свои зависимости кита (`radix-ui`,
`lucide-react`, шрифты) ставятся вместе с ним. `motion` — необязательный peer: ядро кита его не использует,
ставит тот экран, которому он нужен (см. шаг 5).

## 2. Глобальные стили — один раз, до кода приложения

```tsx title="main.tsx"
// Шрифты, токены, сброс, keyframes, эффекты. Первым импортом: CSS приложения их уточняет, а не наоборот
import '@haunt/ui/styles';

import { initEffects, initTheme } from '@haunt/ui';

// Тема и уровень эффектов ставятся на <html> до первого рендера — сохранённая светлая тема не мигнёт тёмной
initTheme();
initEffects();
```

Почему отдельным входом, а не внутри `ThemeProvider`: всё, кроме CSS, `styles.ts` и `signal.ts`, помечено
`sideEffects: false`. Неиспользуемый компонент выпадает из сборки вместе со своим CSS, а глобальные стили так
выпасть не должны — поэтому они вынесены в вход с побочными эффектами.

## 3. Провайдеры в корне

```tsx title="app.tsx"
import { AmbientBackground, ThemeProvider, Toaster, UiStringsProvider } from '@haunt/ui';

export function App() {
  return (
    // Язык кита. Без провайдера — русский; снаружи всего, чтобы тосты и порталы тоже его получили
    <UiStringsProvider locale="ru">
      {/* Тема, уровень эффектов, провайдер подсказок, прожектор за курсором */}
      <ThemeProvider>
        {/* Живой фон — один раз под экран; сквозь зазоры между островами AppShell он и виден */}
        <AmbientBackground variant="dots" reaction="quiet" />

        <Routes />

        {/* Один на приложение: toast.success(…) можно звать откуда угодно, даже из сервиса */}
        <Toaster />
      </ThemeProvider>
    </UiStringsProvider>
  );
}
```

| Провайдер / компонент | Что даёт                                                              | Без него                                         |
| --------------------- | --------------------------------------------------------------------- | ------------------------------------------------ |
| `UiStringsProvider`   | язык подписей кита (`ru`, `en`), перезапись отдельных строк           | всё по-русски                                    |
| `ThemeProvider`       | `useTheme()`: тема и уровень эффектов, подсказки, прожектор           | подсказки не работают, `useTheme` бросает ошибку |
| `Toaster`             | вьюпорт уведомлений, грузится лениво при первом `toast`               | `toast.*` ничего не покажет                      |
| `AmbientBackground`   | живой фон (`dots`, `blobs`, фоны `fx`) с реакцией на курсор и события | ровный фон темы — тоже нормально                 |

## 4. Первый экран

Экран собирается из примитивов: оболочка раскладывает, `Surface` даёт заливку, списки и текст — внутри.
Ниже — живой пример, а не картинка: потяните желоб между островами, сверните панель кнопкой.

<FirstScreen />

```tsx title="pages/space/ui/space-page.tsx"
import { AppShell, Surface, Stack, NavItem, RailItem, Avatar, Text } from '@haunt/ui';

export function SpacePage() {
  return (
    <AppShell
      rail={<SpacesRail />}
      sidebar={
        <Surface level={1} panel border={false} radius="none">
          <Stack gap={0} p={2}>
            <NavItem active>общий</NavItem>
            <NavItem>новости</NavItem>
          </Stack>
        </Surface>
      }
      members={<MembersPanel />}
      header={<StreamHeader />}
      autoSaveId="space" // ширины и свёрнутость переживают перезагрузку
    >
      <Surface level={2} panel border={false} radius="none">
        <Text>Лента потока</Text>
      </Surface>
    </AppShell>
  );
}
```

Что важно уже на первом экране:

- **Импорт только из `@haunt/ui`** (и пяти входов ниже). Глубокие пути вроде `@haunt/ui/src/button/button` —
  внутренности: их можно переименовать без предупреждения.
- **Высоту оболочке задаёт родитель.** `AppShell` занимает 100 % по высоте; у корня приложения это `100vh`
  (`html, body` — 100 % уже в сбросе кита).
- **Оболочка меряет себя, а не окно.** Уже 1100 px участники уходят в `Sheet`, уже 760 px — сайдбар. Пороги —
  проп `breakpoints`. Поэтому оболочка ведёт себя одинаково в окне, во фрейме Storybook и в окне Tauri.
- **Кнопки панелей — через `useAppShell()`** в шапке: `toggleSidebar`, `toggleMembers`, `closeSheet`.

## 5. Дополнительные входы — только там, где нужны

| Вход               | Что внутри                                            | Когда подключать                                                        |
| ------------------ | ----------------------------------------------------- | ----------------------------------------------------------------------- |
| `@haunt/ui`        | компоненты, тема, строки, движение без Motion         | всегда                                                                  |
| `@haunt/ui/styles` | шрифты, токены, сброс, keyframes, эффекты             | один раз в `main.tsx`                                                   |
| `@haunt/ui/signal` | стиль «сигнал» и его дисплейные шрифты                | на экране со стилем: из `main.tsx` стартовый CSS вырос бы с 22 до 69 kB |
| `@haunt/ui/fx`     | рантайм эффектов (WebGL2 → Canvas 2D → статика), фоны | эффекты компонентов, `FxBackground`, `ImageTransition`                  |
| `@haunt/ui/sound`  | синтезированные звуки интерфейса                      | когда экран что-то озвучивает; по умолчанию звук выключен               |
| `@haunt/ui/motion` | пресеты Motion и `MotionProvider`                     | только экранам с `motion` в своих зависимостях                          |

Тяжёлое кит грузит сам и лениво: рендер `Markdown`, подсветку `CodeBlock`, набор `EmojiPicker`, ядра и шейдеры
`fx`, генератор `QrCode`, `Tour`, вьюпорт `Toaster`. Делать для них `lazy()` в приложении не нужно.

## Как найти нужный компонент

1. **Сайдбар Storybook** сгруппирован так же, как таблица в `packages/ui/README.md`: Раскладка, Текст, Кнопки,
   Поля, Отображение, Данные, Списки, Всплывающее, Сообщество, Блоки, Медиа, TUI, Сигнал, Движение, Эффекты,
   Фон.
2. **Страница Docs** компонента собирается сама: описание из JSDoc, таблица пропсов, истории-состояния. Над
   каждой историей — кнопка **Show code**: готовый JSX для вставки.
3. **Панель Controls** у истории меняет пропсы на лету: так видно, что компонент умеет, без чтения кода.
4. **Поиск** в сайдбаре (клавиша `/`) ищет и по названиям историй: «пустое», «ошибка», «длинный текст».
