# Haunt UI

Дизайн-система веб-клиента Haunt — платформы общения и сообществ. Код кита — `packages/ui/src`,
импорт только из публичного API: `import { Button } from '@haunt/ui'`.

**Основа** — нейтральная серая палитра и семантика переменных в духе [Fumadocs](https://www.fumadocs.dev) и
shadcn: `background`, `foreground`, `card`, `popover`, `muted`, `primary`, `secondary`, `border`, `ring`.
Чёткие тонкие рамки, карточки, спокойная типографика. **Характер** — свой: плотное десктопное приложение, где
собираются со своими, — контролы 24 / 28 / 32 px, острова панелей над живым фоном, стекло у плавающих слоёв,
акцент пространства и его аура, след автора в ленте, TUI-словарь и стиль «сигнал». Тёмная тема — основная,
светлая — вторичная.

## Что здесь есть

| Раздел                  | Что внутри                                                                                   |
| ----------------------- | -------------------------------------------------------------------------------------------- |
| **Токены**              | основа и прежние имена, текст, отступы, высоты, скругления, тени, движение — живые значения  |
| **Движение и эффекты**  | уровни `off` / `subtle` / `rich`, что где включается и гаснет                                |
| **Как собирать экраны** | композиция из примитивов и мини-мессенджер на `/ui`                                          |
| **Тема … Всплывающее**  | по странице на примитив: истории-состояния, таблица пропсов, код                             |
| **Блоки**               | `Card`, `Steps`, `CodeBlock`, `FileTree` — блоки документации; из них собраны и эти страницы |
| **Медиа**               | `FilteredImage` — пиксели, дизеринг Байера и ASCII на палитре темы                           |

У каждого примитива страница **Docs** (собирается сама из историй и JSDoc пропсов) и истории — по одной на
состояние: варианты, размеры, disabled, loading, invalid, длинный текст. Пропсы истории меняются на панели
**Controls**.

## Как устроено

Компоненты не знают про Storybook. Тема, акцент и уровень эффектов доходят до них так же, как в приложении:
атрибутами и CSS-переменными на `<html>`. Каждую историю оборачивает декоратор — `ThemeProvider` (Motion,
провайдер подсказок, прожектор), `Toaster` и, если выбран, живой фон. Сейчас акцент — <TokenValue name="--accent" />,
фон холста — <TokenValue name="--background" />.

## Тулбар

Переключатели сверху меняют окружение всех историй и этой страницы сразу; тема переключает и сам интерфейс
Storybook.

| Кнопка               | Значения                                     | Что меняет                                                               |
| -------------------- | -------------------------------------------- | ------------------------------------------------------------------------ |
| **Тема**             | тёмная / светлая                             | `data-theme` на `<html>`: все цветовые токены                            |
| **Акцент**           | violet, indigo, teal, lime, amber, rose, sky | `--accent`, `--accent-2`, `--accent-contrast` — как у `AccentScope`      |
| **Фон**              | без фона / пятна / точки                     | `AmbientBackground` под историей; по умолчанию выключен                  |
| **Реакция**          | выкл / тихо / заметно                        | `reaction` живого фона: курсор, клики, `ambient.pulse`                   |
| **Эффекты**          | без / тихо / ярко                            | `data-effects`: прожектор, отблески, зерно, всплески, фильтр изображений |
| **TUI**              | вкл / выкл                                   | `data-tui`: знаки словаря и компоненты раздела TUI                       |
| **Стиль**            | основа / «сигнал»                            | `data-style="signal"`: кислотный акцент, прямые углы, засечки, капитель  |
| **Шрифт**            | десять дисплейных шрифтов «сигнала»          | `data-signal-font` — для выбора владельцем                               |
| **Акцент «сигнала»** | lime, magenta, cyan, orange                  | `data-signal-accent`                                                     |
| **Язык**             | ru / en                                      | `UiStringsProvider`: подписи кита и форматы дат и чисел                  |

Значения не сохраняются в `localStorage` приложения: выбор в Storybook не влияет на `pnpm dev:web`.

## Проверки

Каждая история — ещё и тест: `pnpm --filter @haunt/ui test:stories` рендерит её в Chromium и выполняет
play-функцию (открыть меню, нажать Esc, проверить фокус). Ход play-функции виден на панели **Interactions**,
проверки доступности — на панели **Accessibility**.

## Команды

```sh
pnpm --filter @haunt/ui storybook          # dev-сервер на http://localhost:6006
pnpm --filter @haunt/ui build-storybook    # статическая сборка в packages/ui/storybook-static
pnpm --filter @haunt/ui test:stories       # истории как тесты в Chromium
pnpm verify:js                             # линт, prettier, типы и все тесты — перед коммитом
```

Как всё это настроено и почему — [Storybook изнутри](?path=/docs/руководство-storybook-изнутри--docs) и
`packages/ui/.storybook/README.md`.
