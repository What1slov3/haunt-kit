# Стиль «сигнал»

Дополнение к основному стилю в духе визуального языка Marathon (Bungie), как мы его понимаем: кислотные
цвета на почти-чёрном и на «бумаге», плотная техническая типографика, разметка как на чертеже или упаковке
(срезы, засечки, метки совмещения, индексы, штрихкоды, серийники), дух постеров The Designers Republic и Y2K.
Логотипы, знаки и шрифты игры не копируются — берётся язык.

**Дополняет, а не меняет.** Без `data-style="signal"` ни одно правило стиля не срабатывает: кит выглядит
пиксель в пиксель как раньше (проверено снимками историй до и после). Включение — на любом контейнере:

```tsx
// main.tsx — один раз, после @haunt/ui/styles
import '@haunt/ui/signal';

// экран события, «магазин ролей», лендинг пространства
<SignalScope font="archivo" accent="lime">
  …
</SignalScope>;
```

В тулбаре: **Стиль** (основной / сигнал), **Шрифт сигнала** и **Акцент сигнала** — ставят атрибуты на
`<html>`, все истории каталога открываются в стиле.

## Как устроено

| Слой              | Что                                                                                                                        |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Токены основы     | стиль переопределяет `--background`, `--text*`, статусы, `--border*`, радиусы (все 0) — компоненты читают те же имена      |
| Ручки компонентов | `--heading-*`, `--micro-*`, `--control-*`, `--radius-pill`, `--frame-ticks` — компоненты читают их с запасным видом основы |
| Переключатели     | `data-signal-font`, `data-signal-accent` на любом контейнере внутри стиля                                                  |
| Порталы           | `SignalScope` заводит хост с теми же атрибутами: меню и подсказки внутри — в стиле                                         |
| Элементы стиля    | `ChamferPanel`, `CornerFrame`, `DataPlate`, `Barcode`, `QrCode`, `HazardStripe`, `RegistrationMarks`, `IndexLabel`…        |

## Палитра

Кислотный акцент (лайм, маджента, циан, сигнальный оранжевый) и статусы на почти-чёрном `#0b0b0a` и на
бумаге `#ecebe4`. Контраст с фоном считается здесь же, по живым значениям (WCAG 2.x, AA — от 4.5):

<SignalPalette />

На бумаге кислотный цвет не годится для текста (лайм на `#ecebe4` — 1.03), поэтому текст из акцента там —
50 % к чёрному в oklab (`--accent-text-amount`), а сам акцент остаётся заливкой с чёрными чернилами.

## Шрифты — для выбора

Одна и та же композиция всеми десятью вариантами — латиницей и кириллицей: заголовок, индекс, цифры, штамп.
У каждого свои поправки кегля и трекинга (`--signal-font-scale`, `--signal-font-tracking`), чтобы прописные
были одной высоты (высота «H» измерена в браузере, scale = 0.73 / высота).

| Шрифт                                        | Кириллица | Характер                                  |
| -------------------------------------------- | --------- | ----------------------------------------- |
| Archivo широкий / узкий, Space Grotesk       | нет       | гротеск; русский заголовок — Inter        |
| Big Shoulders, Chakra Petch                  | нет       | узкий плакатный / технический с фасками   |
| Unbounded                                    | есть      | очень широкий, геометрический, «Y2K»      |
| Oswald                                       | есть      | узкий плакатный                           |
| Exo 2                                        | есть      | технический, «научная фантастика»         |
| Tektur широкий / узкий (ось `wdth` 75–100 %) | есть      | технический с прямыми срезами, две ширины |

У шрифтов без кириллицы русский текст рисуется Inter — следующим в стеке; это видно во второй строке
каждой карточки.

## Формы

| Токен                                         | Значение       | Что                                           |
| --------------------------------------------- | -------------- | --------------------------------------------- |
| `--chamfer-sm` / `--chamfer` / `--chamfer-lg` | 6 / 10 / 18 px | срез угла `ChamferPanel`                      |
| `--frame-tick`, `--frame-tick-width`          | 8 px, 1 px     | засечки `CornerFrame`, `Card`, `Dialog`       |
| `--hairline`, `--dash`, `--dash-gap`          | 1 / 4 / 3 px   | линии, штрих-разделители `DataPlate`          |
| `--hatch`, `--hatch-gap`, `--hatch-angle`     | 6 px, −45°     | штриховка (`ChamferPanel hatch`, заглушки)    |
| `--micro-*`                                   | 10 px, 0.14em  | моно-капитель подписей, меток, индексов       |
| `--control-*`                                 | моно, 0.06em   | капитель кнопок, вкладок, сегментов           |
| `--radius-*`, `--radius-pill`                 | 0              | прямые углы; круг — только у людей и спиннера |
