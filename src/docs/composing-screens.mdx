# Как собирать экраны

Экран Haunt — это лейаут страницы, шапка и примитивы из `@haunt/ui`. Своих цветов, высот и отступов у экрана
нет: всё берётся из токенов и пропсов. Своя раскладка (CSS Module) — только если ни один лейаут не подошёл.

Готовый пример — **мини-мессенджер на `/ui`**: `pnpm dev:web` и [http://localhost:5173/ui](http://localhost:5173/ui).
Рейл → каналы → чат → участники, отправка по Enter, реакции, контекстное меню, смена канала. Там же —
секция эффектов и переключатели темы, акцента, фона и TUI. Код — `apps/web/src/pages/ui-showcase`.

## Слои экрана

1. **Живой фон** — `<AmbientBackground />` один раз под экраном.
2. **Панели** — `Surface panel level={1 | 2 | 3}`: рейл → боковая панель → содержимое. Почти непрозрачные,
   с зерном и прожектором.
3. **Внутри панелей** — `Surface level` без `panel` для карточек, `ScrollArea grow` для прокрутки,
   `NavItem` и `RailItem` для списков.
4. **Плавающее** — меню, поповеры, диалоги, тосты. Стекло только здесь; порталы сами берут акцент и тему
   ближайшего `AccentScope` / `ThemeScope`.

## Лейаут и шапка страницы

Страница внутри области содержимого `AppShell` начинается с лейаута — он решает колонки, ширину и прокрутку:

| Страница                   | Лейаут                                         | Шапка                       |
| -------------------------- | ---------------------------------------------- | --------------------------- |
| Лента и форум пространства | `PageLayout width="wide"` + `aside`            | `SpaceHeader`               |
| Чат места                  | `ChatLayout` (лента, композер, панель треда)   | `PlaceHeader`               |
| Документ, пост, вики       | `PageLayout width="reading"` + оглавление      | `ArtifactHeader`            |
| Настройки                  | `SettingsLayout` (разделы, форма, «сохранить») | заголовок раздела в лейауте |
| Обзор, каталог             | `PageLayout width="wide"` без `aside`          | `Heading` или `SpaceHeader` |

**Отзываются на ширину своего места, а не окна.** В `AppShell` ширину содержимого меняют боковая панель и
панель участников, окно об этом не знает — поэтому в лейаутах нет точек перелома по `@media`: боковая колонка
уходит под основную сама (`WithSidebar`), панель треда в `ChatLayout` ложится поверх ленты по ширине самой
раскладки (container query). Свои куски экрана собирайте так же.

## Примитивы раскладки

`Stack` — колонка, `Inline` — ряд (по умолчанию центрирует по вертикали), `Grid` — сетка. Промежутки —
числом из шкалы: `gap={1.5}` → `--space-1-5`. Для обрезания текста флекс-ребёнку нужен `grow`
(он же ставит `min-width: 0`), а тексту — `truncate`. Сверх них:

| Примитив              | Когда                                                                         |
| --------------------- | ----------------------------------------------------------------------------- |
| `Container`           | колонка по центру: `narrow` 560, `reading` 720, `wide` 1120, `full`           |
| `Spacer`              | развести соседей во флекс-ряду: заголовок слева, действия справа              |
| `Center`              | загрузка, пустое состояние посреди панели (`fill`)                            |
| `WithSidebar`         | основная и боковая части; боковая уходит вниз, когда основной тесно           |
| `Switcher`            | ряд, который целиком становится столбцом уже `threshold` (статистика, тарифы) |
| `Reel`                | горизонтальная лента с прокруткой (карусель пространств, вложения)            |
| `Bleed`               | выйти за поле родителя: обложка до краёв карточки                             |
| `Layer` + `LayerItem` | слои друг над другом: значок на аватаре, подпись и кнопка на обложке          |
| `Sticky`              | прилипнуть к краю прокрутки; прилипший — на стекле, `onStuckChange`           |
| `Masonry`             | галерея плиток разной высоты без дыр, порядок чтения сохраняется              |

## Правила композиции

- **Цвета — только токены.** Если в экране понадобился hex, не хватает токена или варианта примитива.
- **Одна высота на ряд.** Кнопка и поле одного `size` — одной высоты и кегля; композер — `FieldFrame`
  с голым `Textarea bare` и кнопками внутри одной рамки.
- **Скругление по вложенности:** внутренний радиус = внешний − отступ.
- **Состояния — из примитивов.** Выбранное, активное, непрочитанное — пропсы (`active`, `selected`, `unread`),
  а не свой CSS.
- **Акцент сообщества** — `<AccentScope accent="teal">` вокруг экрана пространства; меню внутри окрасятся сами.
- **Реакция на действие** — `ambient.pulseFrom(element)` из обработчика (отправка сообщения), фон ответит
  в меру своего `reaction`.

## Когда нужен новый примитив

Если один и тот же кусок раскладки повторяется на двух экранах и у него есть состояния, это примитив:
папка в `packages/ui/src/<name>/`, экспорт в `index.ts`, история `<name>.stories.tsx` рядом. Как — в
`packages/ui/README.md` и `packages/ui/.storybook/README.md`.
