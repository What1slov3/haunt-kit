# 0014. Кит 1.0 и повторная заморозка

**Контекст.** После заморозки `0013` владелец продолжил достраивать кит «готовым на будущее»: звук (мотивы,
эффекты, генератор), токены из кода, примитивы раскладки, лейауты страниц и шапки сообществ, полировка
переключателей и списков. `0013` разрешает пересмотр только новым решением — это оно.

**Решение.**

- Всё сделанное после `0013` входит в версию **1.0.0** `@haunt/ui` (`packages/ui/CHANGELOG.md`) — одним коммитом
  с тегом `ui-v1.0.0`.
- С 1.0 кит снова заморожен по правилам `0013`: новый компонент — только когда его требует настоящий экран;
  правки существующих — по багам и нуждам экранов. `AppShell` владелец наполняет своим интерфейсом сам.
- Изменение публичного API после 1.0 — запись в `CHANGELOG.md` с версией: исправление — 1.0.x, новое без поломки —
  1.x.0, поломка — 2.0.0. Пакет из исходников (решение 15 в `ui-kit.md`), так что версия — договорённость для
  читателя, а не для менеджера пакетов.

**Варианты.** Продолжать без версии — граница «до заморозки / после» терялась бы, а с ней и ответ на вопрос «что
кит обещает». Выпускать по версии на каждую пачку — для кита без внешних потребителей лишний учёт.

**Последствия.** Следующий шаг — тот же, что в `0013`: первая вертикальная фича (пространства) и экраны на ките.
Лейауты и шапки проверяются этими экранами; что не пригодится — кандидат на удаление в 2.0, а не на поддержку.
