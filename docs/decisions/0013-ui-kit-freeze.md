# 0013. Заморозка кита после волны 3

**Контекст.** Кит `@haunt/ui` за несколько дней вырос до ~110 компонентов и ~35 тыс. строк, а у продукта нет ни
одной доменной фичи (на момент решения — 217 строк Rust). Кит пишут агенты, но решения, ревью и владение кодом —
на владельце; каждая новая волна откладывает первый настоящий экран. Прошлые проекты умирали на подготовке —
это та же ловушка, только дешевле.

**Решение.** Доделать весь намеченный план и заморозить кит:

1. Волна 2 (`research/ui-kit-extensions.md`) и волна 3 целиком (`research/ui-kit-wave3.md`, «Предлагаемый
   порядок»: эффекты и фильтры, стиль «сигнал», строки en / ru, сообщество и оболочка, фоны, эффекты
   компонентов, движение, звук, графики).
2. Финальный проход по всему киту: единый стиль API (имена пропсов, размеры, управляемый и неуправляемый
   режим, `className` / `wrapperClassName`, подписи и строки), визуальная согласованность, документация, тесты.
   Неиспользуемое помечается `experimental` в README.
   Перед проходом — **аудит** (просьба владельца 2026-10-26), чтобы не потерять базовое:
   - **полнота:** инвентарь кита против эталонов — примитивы Radix, каталоги shadcn/ui и Fumadocs UI — и против
     сценариев первого этапа (`decisions/0005`): вход и регистрация, пространства и каналы, лента сообщений с
     вложениями, голос, участники, настройки, события. Каждый шаг сценария разложить на элементы и отметить, чем
     он закрывается; пробелы — в план до заморозки (так уже найден `MessageMedia`);
   - **регрессии:** то, что работало до волн, работает и после — истории и e2e, витрина `/ui`, совместимость API
     (список изменённых пропсов, например `DatePicker className`), вес стартового чанка, `data-effects` / `data-tui` /
     reduced-motion / тема / акцент на старых компонентах.
3. После прохода — заморозка: новый компонент появляется, только когда его требует настоящий экран; правки
   существующих — по багам и по нуждам экранов. Волн больше нет.

**Последствия.** Следующий шаг после заморозки — внешняя страница сервиса (лендинг со входом, регистрацией,
восстановлением — вёрстка без логики), затем первая вертикальная фича по `architecture.md` (пространства:
миграция → протокол → модуль → тест → экран). Кит проверяется настоящими экранами; что не пригодится — кандидат
на удаление, а не на поддержку. Пересмотреть решение можно новым решением со ссылкой на это.

## Выполнено (2026-10-27)

- Волны 2 и 3 — целиком; из инфраструктуры волны 3 сделаны строки en / ru, остальное (визуальная регрессия,
  a11y → `error`, плотность, редактор темы, свои иконки) — не в плане заморозки.
- Аудит — `research/ui-kit-audit.md`: найденные пробелы закрыты (`PasswordInput`, `ImageCropper`, `MessageItem`,
  `ReplyPreview`, `UnreadDivider`, `DateDivider`, `JumpToLatest`, `AspectRatio`, `VisuallyHidden`), регрессий
  нет: 2568 тестов кита и e2e витрины зелёные, стартовый чанк — 65 kB кода + React, CSS — 21 kB.
- Финальный проход — `research/ui-kit-work/final-pass-notes.md`. Отступление от пункта 2: пометка
  `experimental` не ставится — кит, кроме витрины, не применён ни одним экраном, пометка была бы на всём; вместо
  неё долг в `ui-kit.md`.
- С этого дня кит заморожен. Открыто у владельца: выбрать шрифт стиля «сигнал», вычитать en-словарь.
